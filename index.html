// About

A map for the free tool jungle.

Toolstack exists because finding a decent free online tool usually means wading through SEO spam, dark-pattern paywalls and ad-choked converters. This site is a hand-curated index of tools that actually work — each one scored on whether it's truly free, requires signup, respects your privacy, drowns you in ads, and how easy it is to use.

It's a fully static site: no backend, no database, no tracking. All tool data lives in one local file, so the directory is easy to extend, audit, and bookmark.
